# 📈 Study Rules

* 하루 최소 1문제 이상 풀이
* 풀이 후 코드 리팩토링
* 시간복잡도와 공간복잡도 분석
* 새로운 알고리즘은 별도 정리
* 이전 문제를 주기적으로 다시 풀이
